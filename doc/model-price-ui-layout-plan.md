# 方案：优化模型价格手动填写与保存的 UI 布局

## 1. 目标

优化“模型价格设置”页面中手动新增、编辑、保存价格的布局，解决当前输入框、下拉框、按钮排列杂乱的问题。

本次只输出方案，不改代码。

---

## 2. 当前问题

- 字段多但缺少分组，视觉层级不清晰。
- 模型、风格、价格、倍率、保存按钮混在一起。
- 选择 `peak` 后字段更多，布局更乱。
- 保存按钮位置不固定。
- 已保存价格列表与编辑弹窗的布局也不统一。

---

## 3. 目标布局

### 3.1 新增价格表单

采用“**基础信息在上、价格输入在下**”的结构，并移除底部独立操作栏，保存按钮放在基础信息区右侧。

```text
┌ 基础信息 ─────────────────────────────────────────┐
│ 模型选择           计价风格                   保存 │
└───────────────────────────────────────────────────┘

┌ 价格输入 ─────────────────────────────────────────┐
│ 非 Peak 模式（默认）                                │
│ 输入价   输出价   缓存读   缓存写   倍率            │
│                                                   │
│ Peak 模式（仅选择 Peak 时显示）                     │
│ Peak Time: Start/End 区间列表                      │
│ Off-peak: 输入/输出/缓存读/缓存写                  │
│ Peak:     输入/输出/缓存读/缓存写                  │
└───────────────────────────────────────────────────┘
```

说明：
- **非 Peak / Peak 互斥显示**，两者不同时出现。
- 不选择 `peak` 时，价格输入区只显示：
  - 输入价 / 输出价 / 缓存读 / 缓存写 / 倍率
- 选择 `peak` 时，价格输入区只显示 Peak 表单：
  - Peak Time（放在最上方）
  - Off-peak：输入 / 输出 / 缓存读 / 缓存写
  - Peak：输入 / 输出 / 缓存读 / 缓存写
  - **不显示倍率输入框**
- 保存按钮固定在基础信息区右侧，不再单独占一行。

### 3.2 已保存价格编辑弹窗

**不使用新增表单的布局**，保持当前编辑弹窗整体结构，只在此基础上追加 Peak 编辑能力。

规则：
- 非 Peak 模式：保持当前字段顺序，倍率输入框正常显示。
- 选择 `peak` 时，编辑弹窗内按以下方式展示：
  ```text
  ┌ 编辑弹窗 ────────────────────────────────────────┐
  │ 模型名 / 计价风格（保持当前布局位置）             │
  │                                                  │
  │ Peak Time（保持当前布局位置）                     │
  │                                                  │
  │ Off-peak 输入            Peak 输入               │
  │   输入价                   输入价                │
  │   输出价                   输出价                │
  │   缓存读                   缓存读                │
  │   缓存写                   缓存写                │
  │                                                  │
  │               [取消] [保存]                       │
  └──────────────────────────────────────────────────┘
  ```
  - 计价风格下拉与当前布局保持一致，不移动位置
  - Peak Time 与当前布局保持一致，不移动位置
  - 价格输入区做成**双栏**：
    - 左栏：Off-peak 输入
    - 右栏：Peak 输入
    - 两栏内部字段一一对齐，每个字段单独一行
  - **不显示倍率输入框**
  - 保存/取消按钮与当前实现保持一致，不改成填满宽度
- 模型名保持只读。

---

## 4. 边距与对齐约束

采用统一 **8px 间距网格**。

### 4.1 间距
- 区块内间距：`8px`
- 区块间间距：`16px`
- 卡片内边距：`16px` 或 `20px`
- 表单行间距：`12px`
- 输入框与标签间距：`4px`
- 保存按钮与下拉框间距：`12px`

### 4.2 对齐
- 所有标签统一放在输入框上方，左对齐。
- 所有输入框 / 下拉框高度保持一致，例如 `36px`。
- 同一行内字段使用相同宽度比例：
  - 五个价格字段（输入价/输出价/缓存读/缓存写/倍率）默认均分一行。
  - 模型选择与计价风格默认各占 50%。
- Peak 双栏中：
  - 左列 Off-peak、右列 Peak 宽度完全一致。
  - 两列内部字段一一对齐。
  - Peak 模式不显示倍率输入框。
  - Peak Time 放在 Off-peak input 上方。
- 保存按钮与基础信息区右侧对齐，不随内容换行漂移。

### 4.3 响应式
- 宽屏：价格字段 5 列，基础信息 2 列 + 保存按钮。
- 中屏：价格字段可降为 3 列或 2 列。
- 窄屏：所有字段单列堆叠，保存按钮占满一行或右对齐。
- 不出现横向滚动。

---

## 5. Peak 模式交互

- 切换为 `peak` 时，普通价格表单隐藏，只显示 Peak 表单；切换回非 Peak 时恢复普通价格表单。
- 新增表单 Peak 模式：
  - Peak Time 显示在双栏上方。
  - 下方为 Off-peak / Peak 双栏。
  - 不显示倍率输入框。
- 编辑弹窗 Peak 模式：
  - 计价风格下拉与当前布局保持一致，不移动位置。
  - Peak Time 与当前布局保持一致，不移动位置。
  - 价格输入区为双栏：左 Off-peak、右 Peak，内部字段竖排且对齐。
  - 不显示倍率输入框。
  - 保存/取消按钮与当前实现保持一致。
- 若 Peak 输入为 0 而 Off-peak 非 0，保存时提示无法计算倍率。
- PeakTimeEditor 的 Start/End 下拉宽度与模型/风格下拉保持一致。

---

## 6. 已保存价格列表优化

- 每个价格项改为两行卡片：
  - 第一行：模型名 + 操作按钮（规则、编辑、删除）
  - 第二行：价格指标横向排列，标签 + 值
- 操作按钮统一右侧固定宽度。
- 搜索框固定在列表标题下方。
- 无匹配结果时显示明确空状态。

---

## 7. 保存与反馈

- 新增表单：保存按钮固定在基础信息区右侧。
- 编辑弹窗 Peak 模式：保存/取消按钮与当前实现保持一致。
- 保存中显示 loading，禁用重复提交。
- 保存成功后：
  - 新增表单清空
  - 已保存价格列表刷新
  - 提示成功
- 保存失败时：
  - 高亮对应输入框
  - 在表单顶部显示错误信息
  - 不丢失已填内容

---

## 8. 边界与注意事项

1. `peak` 模式只影响 UI 展示，不改变后端价格模型。
2. 非 Peak 模型不要展示 Peak 区域。
3. 模型下拉仍使用现有 `buildPricingModelOptions` 逻辑。
4. 搜索框只过滤“已保存价格”，不影响新增模型下拉。
5. 新增表单使用新布局；编辑弹窗保持当前布局，只追加 Peak 编辑能力。
6. 窄屏下所有多列布局自动变为单列。
7. 不引入新的 UI 组件库，沿用现有 `Card / Input / Select / Button / Modal`。

---

## 9. 代码规范

- 沿用现有 `PriceSettingsCard.tsx` 结构，不新增重型状态管理。
- 拆分子组件：
  - `PriceInputsGrid`：价格输入网格
  - `PeakPriceInputs`：Peak 模式双栏输入
  - `BasicInfoRow`：模型选择 / 计价风格 / 保存按钮
- 样式放在独立 SCSS 文件或现有 `UsagePage.module.scss` 的分区中。
- 使用 SCSS 变量定义间距：
  - `$space-1: 4px`
  - `$space-2: 8px`
  - `$space-3: 12px`
  - `$space-4: 16px`
  - `$space-6: 24px`
- 表单状态继续使用 `useState`，校验逻辑抽成独立函数。
- 多语言：所有新增文案（Peak Time、Off-peak、Peak、Add peak range、Remove 等）统一加入 `en / zh / zh-TW` i18n，不硬编码。
- 相关测试覆盖：
  - 非 Peak / Peak 布局切换
  - 基础信息区在上、价格输入区在下
  - 保存按钮位置
  - 窄屏堆叠
  - 保存成功/失败反馈
  - 搜索过滤与空状态

1. 重构新增价格表单为“基础信息 / 价格输入”两个分区。
2. 将保存按钮移入基础信息区右侧。
3. 实现 Peak 双栏布局与 PeakTimeEditor 对齐。
4. 同步调整已保存价格编辑弹窗布局。
5. 优化已保存价格列表卡片。
6. 统一 8px 间距与响应式规则。
7. 运行：
   - `npm run typecheck`
   - `npm run lint`
   - `npm test -- --run`
